#
Eitri
的按键
这份教程讲的是这个编辑器所在的
Eitri
窗口的按键：前缀、模块、agent
面板、
底部终端、浮动窗口和工作区。每一步都做的话，大约要十五分钟。
Neovim
自己的按键在这里照常可用。用
`j`{normal}
往下翻这一页。你在这一页里
输入的内容永远不会写到磁盘上。
#
第
0
课
这份教程的大多数步骤发生在
nvim
之外、在窗口里：每一步都会说你应该看到什么，
以及怎样回到这里。有一个办法总能回来：从任何别的模块按
`Ctrl+b
e`，按键就回到
这个编辑器。（如果编辑器已经拿着按键，它反而会把编辑器隐藏；再按一次就回来。）
按键按默认设置来写，前缀是
`Ctrl+b`。如果
Eitri
从你的
tmux
配置或
init.lua
里拿到了别的前缀，本教程写
Ctrl+b
的地方就按你自己的。第
7
课讲它们从哪里来。
如果你的
tmux
配置还改了前缀之后的键，`Ctrl+b
?`
会显示它们在这里做什么。
左边有
✗
的行需要你来改。这些行大多要你填一个键：按
`A`{normal}，输入一个空格
和这个键（按本教程的写法；组合键就写它的字母，比如
Ctrl+l），再按
`<Esc>`{normal}。改对以后
✗
会变成
✓。在下面这行试一下，它要的是
`?`：
先按前缀，再按这个键，列出所有按键：Ctrl+b
#
第
1
课：前缀
**
按下
Ctrl+b，松开，再按一个键。
**
窗口自己的按键都以前缀开头，和
tmux
一样。Eitri
在编辑器、agent
面板或终端
看到这个键之前就把它读走，所以不管按键在哪里，它都有效。
1.
按下
`Ctrl+b`
再松开。顶栏会出现一条提示条，列出接下来可以按什么，
最后一项是
`?
keys`。
2.
按
`<Esc>`。提示条消失，别的什么也不发生。按一个前缀没绑定的键，也会
结束等待而不做任何事。
3.
按
`Ctrl+b
?`。agent
面板会显示完整的按键表，从前缀之后的那些键开始。
你自己改过的、从
tmux
拿来的，都在里面。用
`q`
或
`<Esc>`
关掉它：
按键会回到这里。
注意：本教程讲的是最常用的键。`Ctrl+b
?`
总是列出全部，提示条则显示前缀之后
能按什么。
#
第
2
课：分割、放大和关闭模块
**
Ctrl+b
%
在右边打开一个模块，Ctrl+b
"
在下面打开。
**
窗口由模块组成：这个编辑器、agent
面板和底部终端。分割键会再等一个键来指明
是哪个模块：`e`
是编辑器，`a`
是
agent
面板，`t`
是终端。如果终端已经开着，
分割键会把它移到那里。
注意：第
3、4
步会关掉底部终端，它的
shell
和在里面运行的一切都会结束，
终端隐藏着时也一样。如果它正在运行你需要的东西，比如构建、服务器或
agent，就跳过第
3、4
步里关闭的那一下：按
`Ctrl+b
e`
回到这里。
1.
按
`Ctrl+b
%`，再按
`t`。终端在编辑器右边打开，并拿到按键。
2.
按
`Ctrl+b
z`。终端占满整个窗口。再按一次
`Ctrl+b
z`，它回到原来的位置。
3.
按
`Ctrl+b
x`。顶栏会问是否关掉这个窗格（kill-pane）。按
`y`：终端里的
shell
结束，终端关闭。按键会到相邻的一个模块；如果那不是这个编辑器，
就按
`Ctrl+b
e`。
4.
按
`Ctrl+b
"`，再按
`t`。这次终端在编辑器下面打开。再用
`Ctrl+b
x`
和
`y`
关掉它。
注意：这个编辑器拿着按键时不要按
`Ctrl+b
x`。那会结束
nvim，这份教程也随之
结束，而且在你打开一个新的
Eitri
窗口之前，编辑器都不会回来；如果
编辑器是屏幕上最后一个模块，Eitri
会整个关闭。
5.
改好下面这行：
放大这个模块，或者恢复：Ctrl+b
#
第
3
课：用
CTRL+H、CTRL+J、CTRL+K、CTRL+L
移动
**
Ctrl+h、Ctrl+j、Ctrl+k
和
Ctrl+l
把按键向左、下、上、右移动。
**
这四个键不用前缀。在
agent
面板里，`Ctrl+j`
在
BROWSE
下开始输入，在消息框里
则向下离开；`Ctrl+k`
从消息框回到
BROWSE，在
BROWSE
下则向上离开（两种模式见
第
4
课）。在
nvim
里，它们先在
nvim
自己的窗口之间移动，那个方向上没有
nvim
窗口了，才去下一个模块，就像
tmux
里的
vim-tmux-navigator
那样。
1.
按
`Ctrl+l`。按键到了右边的
agent
面板。
2.
按
`Ctrl+h`。按键回到这个编辑器。
3.
输入
`:vsplit`{vim}
并按
`<Enter>`。现在
`Ctrl+l`
先移到
nvim
的右半边，
再按一次
`Ctrl+l`
才到面板。按
`Ctrl+h`
回到左半边，然后输入
`:only`{vim}。
4.
还有几种移动按键的办法：
`Ctrl+b
o`
屏幕上的下一个模块
`Ctrl+b
;`
之前拿着按键的那个模块
`Ctrl+b
Left`
那一侧的模块（还有
Right、Up
和
Down）
`Ctrl+b
f`
给能跳去的模块和按钮标上标签；输入标签就跳过去
注意：如果你的
nvim
配置把
`Ctrl+h`、`Ctrl+j`、`Ctrl+k`
或
`Ctrl+l`
映射成了
别的，以你的映射为准，Eitri
不碰那个键。这时就用前缀加方向键。
5.
改好下面这行：
回到之前拿着按键的模块：Ctrl+b
#
第
4
课：AGENT
面板
**
面板有两种模式：INSERT
是消息输入框，BROWSE
是对话。
**
agent
面板是你和
agent
对话的地方。在
BROWSE
里，它的按键是
vim
的。面板底栏
的最左端显示模式，就像你的状态栏显示
nvim
的模式那样。
1.
按
`Ctrl+l`
去面板。如果底栏写着
BROWSE，就按
`i`。
2.
输入几个词，再按
`Ctrl+u`
把它们删掉。这一课里不要按
`<Enter>`：那会把你
输入的内容发给
agent，开始一轮对话。
3.
按
`<Esc>`。底栏写着
BROWSE。在这里，`j`
和
`k`
在对话的各行之间移动，
`?`
列出面板的按键（`q`
关掉），`i`
回到输入框。
4.
每个对话是一个标签页。按
`Ctrl+b
c`：会打开一个新的空标签页，等着它的
第一条消息。`Ctrl+b
n`
和
`Ctrl+b
p`
去下一个和上一个标签页，
`Ctrl+b
1`
去第一个。`Ctrl+b
&`
在你按
`y`
之后关掉当前标签页。用它把
新的那个关掉：先回到新标签页（按
`Ctrl+b
n`，直到到了它上面），再按
`Ctrl+b
&`
和
`y`。在
BROWSE
里，`H`
和
`L`
也能在标签页之间切换。
5.
agent
要运行一个需要你批准的工具时，对话里会出现一张卡片等着你。现在
没有卡片，所以读一读这段：
在
BROWSE
里，`a`
批准光标所在的卡片，`d`
拒绝，`D`
拒绝并让你输入理由
（只在
Claude
标签页；Codex
和
ACP
agent
不收理由，`D`
会这样告诉你）。
`]p`
和
`[p`
移到下一张和上一张等待中的卡片。在
INSERT
里，`Ctrl+y`
批准最早的那张卡片；刚按过
`Ctrl+u`
时，第一下
`Ctrl+y`
不回答，只说明
原因，再按一下才回答。这些键只有单独按下时才会回答卡片，所以你正在打的
字不会误答卡片。
6.
按
`Ctrl+h`
回到这里。
7.
改好下面这行：
在
agent
面板里新建一个标签页：Ctrl+b
#
第
5
课：底部终端，以及连按两次
CTRL+B
**
Ctrl+b
t
显示终端；Ctrl+b
Ctrl+b
发送
Ctrl+b
本身。
**
在终端里，前缀和那四个移动键归
Eitri，shell
永远看不到它们。前缀可以把它们
交还回去。
1.
按
`Ctrl+b
t`。终端在编辑器下面打开，并拿到按键。它的
shell
从项目目录
启动。
2.
输入
`ls`
并按
`<Enter>`。想清屏的话，`Ctrl+l`
不行：它会移动按键。改按
`Ctrl+b
Ctrl+l`，它把
Ctrl+l
发给
shell。`Ctrl+b
Ctrl+h`、`Ctrl+b
Ctrl+j`
和
`Ctrl+b
Ctrl+k`
对那几个键也一样，比如
readline
的
Ctrl+k，它删到行尾。
3.
按
`Ctrl+b
[`
往回翻终端的输出。`k`
和
`j`
移一行，`q`
退出。
4.
按
`Ctrl+b
Ctrl+b`
把
Ctrl+b
发给程序：在
shell
里，它让光标后退一个字符。
在这个终端里运行的
Claude
Code
把它当作把正在运行的命令移到后台的键。
5.
按
`Ctrl+k`。按键回到这里，回到上面的编辑器。按键在终端里时，
`Ctrl+b
t`
会再把终端隐藏。
6.
nvim
也一样，Ctrl+b
在
nvim
里往回翻一页。按
`<C-f>`{normal}
往下翻一页，
再按
`Ctrl+b
Ctrl+b`：nvim
收到
Ctrl+b，翻回这一课。
7.
改好下面这行：
清空终端屏幕：Ctrl+b
#
第
6
课：浮动窗口、便笺板和工作区
**
浮动窗口在其他模块之上，便笺板把浮动窗口收起来，工作区以一个名字保存
一整套排布。
**
1.
按
`Ctrl+b
t`
显示终端并让它拿到按键。
2.
按
`Ctrl+b
Alt+Shift+Space`。终端浮在窗口中间、其他模块之上。编辑器
从不浮动。
3.
按
`Ctrl+b
Alt+_`（在大多数键盘上就是
Alt、Shift
和减号键）。浮动窗口
进了便笺板，看不见了。它在顶栏里的名字现在以
`⌁`
结尾，它的
shell
照常
运行。
4.
按
`Ctrl+b
Alt+-`。它回来了。再按一次，它又收起来；再按一次，又回来。
5.
按键在浮动窗口上时，按
`Ctrl+b
Alt+Shift+Space`
把它放回其他模块中间。
然后按
`Ctrl+b
e`
回到这里。
6.
按
`Ctrl+b
s`。提示条列出各个工作区，最后是
`c
new
·
x
delete`。按
`c`：
Eitri
建出一个新工作区，它是当前排布的一份复制，名字取从
2
起最小的空闲
数字，并把你带过去。按
`Ctrl+b
z`
放大编辑器。
7.
按
`Ctrl+b
L`。你回到了开始时所在的工作区，没有放大，和你离开时一样。
要删掉那份复制，按
`Ctrl+b
s`，再按
`x`，再按提示条上那份复制旁边的
数字；它会立刻被删掉，不会再问。每个工作区里的模块都一样，不同的只是
排布。
8.
改好下面这行：
把这个模块浮起来，或者把浮动窗口放回去：Ctrl+b
#
第
7
课：你的
TMUX
配置，以及
INIT.LUA
**
Eitri
会拿走你的
tmux
前缀和绑定；其余的由
init.lua
来改。
**
如果你用
tmux，Eitri
启动时读过你的
tmux
配置（tmux
会读的那些文件，比如
~/.tmux.conf
或
~/.config/tmux/tmux.conf）。你的前缀，以及能对上
Eitri
动作
的绑定，在这里同样有效。一条通知会说明拿过来了什么，每次变化只出现一次；
`Ctrl+b
?`
会列出每一行没拿过来的，并说明原因。Eitri
只读这些文件，从不启动
或询问
tmux。
你自己的修改写在
~/.config/eitri/init.lua
里（设了
$XDG_CONFIG_HOME
的话，
是
$XDG_CONFIG_HOME/eitri/init.lua）。Eitri
启动时读它，它写的内容优先于从
tmux
拿来的。调用的样子是这样：
~~~
lua
local
k
=
eitri.keymap
k.prefix("C-a")
--
前缀改成
Ctrl+a
k.del("prefix",
"C-b")
--
前缀之后的
Ctrl+b
原来发送
Ctrl+b
k.set("prefix",
"C-a",
"send-prefix")
--
现在连按两次
Ctrl+a
发送
Ctrl+a
~~~
一个已经有动作的键，必须先用
`k.del`
删掉，`k.set`
才能给它别的动作；否则
Eitri
会在启动时停下，并告诉你该改哪一个调用。
1.
下面这行把前缀设成
Ctrl+b。把它改成
Ctrl+a：把光标移到
`b`
上，按
`ra`{normal}。
eitri.keymap.prefix("C-b")
2.
要关掉
tmux
导入，init.lua
里写：
eitri.config.set("keymap.from_tmux",
"off")
Eitri
的源码里带了两个示例，在
docs/keymap/
下：tmux-ctrl-a.lua
把前缀移到
Ctrl+a，并带上一套常见的
tmux
设置；i3-alt-mod.lua
给
$mod
是
Alt
的
i3
或
sway
用。这样的窗口管理器会在
Eitri
之前拿走那些
Alt
组合键（`Ctrl+b
Alt+w`
等等），这个示例把它们改成了
Ctrl+Alt
组合键：用了它，第
6
课的
Ctrl+b
Alt+Shift+Space
变成
Ctrl+b
Ctrl+Alt+Space，Ctrl+b
Alt+_
变成
Ctrl+b
_。
