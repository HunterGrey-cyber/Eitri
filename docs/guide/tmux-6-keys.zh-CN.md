# 没用过 tmux？先记这 6 个键

Eitri 的窗口按键学的是 tmux。如果你一直是在 Neovim 里用 AI 插件、没碰过 tmux，第一次打开可能会有点懵：编辑器旁边多了一个对话面板，`Ctrl+b` 好像也不翻页了。

第一天不用把[按键](keys.zh-CN.md)那一页看完。先记下面 6 个，够你打开项目、跟 agent 说话、看它改了什么。剩下的用到再查，`Ctrl+b ?` 随时能列出来。

下面的键都按默认设置写。

## 1. `Ctrl+h` / `Ctrl+l`：在编辑器和面板之间切

窗口里有好几块（编辑器、agent 面板、终端），你按的键同一时间只会进到其中一块。所以第一件事就是知道怎么把焦点挪过去。

`Ctrl+h` 往左，`Ctrl+l` 往右，`Ctrl+j` 往下，`Ctrl+k` 往上，方向和 vim 的 `hjkl` 一样。在编辑器里，它先在 Neovim 自己的分屏之间走，走到最边上才跨到旁边的模块（Insert 模式下只有 `Ctrl+l` 会跨出去），用过 vim-tmux-navigator 的话会觉得很熟。

- 你的配置已经把这几个键映射成别的功能时，Eitri 不动它们，这时用 `Ctrl+b` 加方向键（`Left`、`Right`、`Up`、`Down`）来移动。
- 底部终端里，shell 的清屏 `Ctrl+l` 被拿来移动了，要清屏就按 `Ctrl+b Ctrl+l`。

## 2. `i` 和 `Esc`：面板里的输入和浏览

agent 面板也分模式，和 vim 一样。不知道这一点，你会以为打字没反应。

- 焦点到了面板后，按 `i` 进入输入框（INSERT），写你的问题，`Enter` 发送，`Shift+Enter` 换行。
- 按 `Esc` 回到浏览（BROWSE），这时 `j` / `k` 在对话里一行一行地走。
- 面板底部左边显示当前是哪种模式，位置和样子跟编辑器状态栏里的模式一样。

agent 回答到一半时，你在输入框里写一句再按 `Enter`，是给它插话，回合不会停。想直接停掉，按 `Ctrl+c`。

想让 agent 看某段代码，先在编辑器里用 Visual 模式选中，再切到面板提问，选中的那几行会跟着发过去。

## 3. `Ctrl+b`，然后 `?`：前缀键，和查所有键的地方

窗口级的操作（开终端、分屏、开新对话、切标签页）都在前缀键后面。这是 tmux 的习惯，也是你最需要适应的一点。

用法是：按 `Ctrl+b`，**松开**，再按一个键。不是三个键一起按。

- `Ctrl+b ?` 列出所有按键。忘了什么就按它。
- 按了 `Ctrl+b` 又不想要了，按 `Esc` 取消。
- `Ctrl+b` 在 Neovim 里本来是向上翻页。现在要翻页，连按两次：`Ctrl+b Ctrl+b`。
- 想要按下前缀后自动提示接下来能按什么，在 `~/.config/eitri/init.lua` 里加一行：`eitri.config.set("keymap.which_key_delay", 200)`。

前缀键可以改，比如很多人习惯 `Ctrl+a`；改法见[按键](keys.zh-CN.md)。

## 4. `Ctrl+b t`：打开终端

跑测试、看 git、装依赖，第一天总要用到终端。

`Ctrl+b t` 显示底部终端，焦点也过去；焦点已经在终端里时再按一次，就把它藏起来，里面的 shell 照样在跑。

想再开一个终端，按 `Ctrl+b Alt+Enter`，它开在当前模块右边，shell 从项目根目录启动。

## 5. `Alt-n`，然后 `1`：回答 agent 的请求

agent 要跑一条需要你批准的命令时，会停在一张卡片上等你。你不回答，它就一直等。

- 卡片来的时候，输入框上方那一行会提示。按 `Alt-n` 接过这张卡片（在输入框里按也行）。
- 再按数字选卡片上的按钮。`1` 是允许，最后一个数字总是拒绝。卡片上有「Always allow」时，`2` 是允许并记住这条规则，以后同类命令不再问。
- 不想现在回答，按 `Esc` 离开，卡片继续等着。

字母键永远不会回答卡片，你正在打字时也不会误按。

同时开着几个 agent 时，`Ctrl+b u` 跳到等你最久的那一个。

## 6. `c`：看这个回合改了什么

agent 干完一轮，你多半想知道它动了哪些文件。

在面板里浏览时（先按 `Esc`）按 `c`，会列出这个回合期间磁盘上变了的文件，可以逐个 hunk 展开。看到不想要的改动：

- `x` 把这个 hunk 改回去，`u` 撤销这次改回；
- `i` 写一句批注，`s` 把批注作为下一条消息发给 agent，发之前会先给你看。

不按 `c` 就什么都不会弹出来。不需要 git 仓库，Eitri 用的是它自己的快照。详细用法见[审阅一个回合](turn-review.zh-CN.md)。

## 接下来

- 编辑器里敲 `:EitriTutor`，跟着练一遍。它讲英文或简体中文，按你的语言环境来选。
- 想多开几个对话、把窗口分成几块，看[快速上手](getting-started.zh-CN.md#arranging-the-window)里的「摆一摆窗口」。
- 在 Hyprland、sway 或 niri 上，Eitri 默认把分屏交给你的窗口管理器，第 1 条里的 `Ctrl+h` / `Ctrl+l` 在对话窗口里就是窗口管理器的焦点移动；见[合成器窗口](compositor-windows.zh-CN.md#keys)。
