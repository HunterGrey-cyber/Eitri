三条关键路径

编辑路径

键盘与鼠标输入进入 shell，由 neovide-editor 驱动真实的 nvim --embed；Skia/Neovide renderer 将编辑状态直接绘制到 GTK 的 GL 区域。

智能体路径

agent-ui/web 通过 shell/core 桥接会话。默认 legacy 启动 Claude CLI；sidecar 经 Verdandi 提供流式事件、权限往返和会话恢复。

Verdandi 运行时路径

terminal-pane 和 semantic-pane 分别消费终端 runtime 与对话投影。它们是独立面板，而非编辑器或 AI 面板的附属视图。

边界比集成更重要

产品窗口只承担编排：GTK 依赖留在 shell 与面板 crate；可测试的协议、路径、主题 token 与 agent backend 边界沉在 neovibe-core。这使 Linux/macOS 的平台工作能从 UI 依赖中分离出来。

  • 默认 agentlegacy；环境变量可选择 sidecar。
  • 权限按能力提供 auto / bypass，而非按后端名称硬编码。
  • 会话恢复sidecar 可用并受 provider handshake 约束；legacy 不提供恢复。
  • 主题nvim colorscheme → core token → GTK chrome 与 WebView 面板。
