# Eitri 0.4

**Draft:** 0.4.0 is not out yet. This page describes main while the release is prepared, and it is read again on the
day 0.4.0 ships; until then the release link below leads nowhere.

0.4 is for running several agents next to your own Neovim, and for letting your window manager and the Neovim in your
terminal join the workspace.

## Highlights

- **See which agent waits for you.** Every Eitri window shares what its agent tabs are doing. `<prefix> u` goes to the
  agent that has waited longest, in whichever window it is, and `<prefix> B` brings you back.
- **Chats and pages your compositor tiles.** On Hyprland, sway and niri each chat and each page opens as a window of
  its own; `window.tiling = "eitri"` keeps them all inside one Eitri window.
- **Move a terminal Neovim into the window.** `:EitriOpen` in Neovim 0.12 or newer brings that same Neovim, unsaved
  changes and all, into an Eitri window, and closing the window gives it back to the terminal.
- **Pick up where you left off.** Starting a project again reopens its files, splits and cursor positions, and
  `<prefix> O` lists your other projects.
- **More of Claude Code in its tab.** Plan mode, pasted images, your open buffers as context, and vim keys in the
  panel.

## Before you upgrade

- **After a `.deb` or `.rpm` upgrade, run `eitri setup` once.** 0.4.0 bundles a newer agent sidecar, and setup builds
  it on your machine (network access, and about 1.4 GiB of free disk while it builds). `sh install.sh` and the AUR
  package build it for you.
- **On Hyprland, sway and niri, chats and pages leave the Eitri window.** To keep the window as it was, add
  `eitri.config.set("window.tiling", "eitri")` to `init.lua`.
- **New default keys after the prefix: `F`, `S`, `_`, `W`, `O`, `u` and `B`.** A key your `init.lua` already binds
  with `eitri.keymap.set` stays yours, and Eitri says once at start which default it left off.
- **On sway or i3 with Alt as `$mod`,** the Alt keys after the prefix move to Ctrl+Alt, unless your `init.lua` sets
  any of them.
- **`eitri-supervisor` is gone.** Load the `agents-top` page, or run `eitri agents --watch`, for the same overview.
- **The 0.4 installer does not install 0.3.0 or older.** Asked for an older version, it stops before it downloads
  anything.
