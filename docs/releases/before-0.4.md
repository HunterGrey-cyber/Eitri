# Before 0.4

Eitri's releases before 0.4, in short. This page has no downloads for them: install the newest release.

- **0.3.0** (31 October 2026), the tiling release: the window became a keyboard-driven tiling manager, Codex and agents
  that speak ACP joined Claude Code, you could put pages of your own in the window, and a Claude Code tab began to show
  the work Claude Code does by itself.
- **0.2.2** (9 October 2026): the user guide, and Bypass tabs that approve every question the Claude Code CLI asks.
- **0.2.1** (4 October 2026): the agent panel beside the Neovim in your terminal, turn review, workspace trust, Auto
  tabs on Claude Code's own auto mode, and your tmux keys imported.
- **0.2.0** (October 2026): the first public release. Your Neovim, run as `nvim --embed`, in a window of its own, with a
  Claude Code panel beside it.
