# 0.4 之前

Eitri 0.4 之前的版本，简单列一下。这里不提供它们的下载：请安装最新版本。

- **0.3.0**（2026 年 10 月 31 日），平铺的版本：窗口变成用键盘操作的平铺管理器，Codex 和讲 ACP 的 agent 加入了 Claude Code 的行列，可以把你自己的页面放进窗口，Claude Code 标签页开始显示 Claude Code 自己做的事。
- **0.2.2**（2026 年 10 月 9 日）：使用指南；Bypass 标签页会批准 Claude Code CLI 问的每一个问题。
- **0.2.1**（2026 年 10 月 4 日）：agent 面板可以放在终端里的 Neovim 旁边，回合审阅，工作区信任，基于 Claude Code 自己 auto 模式的 Auto 标签页，导入你的 tmux 按键。
- **0.2.0**（2026 年 10 月）：第一个公开版本。你的 Neovim 以 `nvim --embed` 运行在它自己的窗口里，旁边是 Claude Code 面板。
