# Eitri 0.4

0.4 让你在自己的 Neovim 旁边同时跑几个 agent，也让你的窗口管理器和终端里的 Neovim 加入这个工作环境。

## 重点

- **看出哪个 agent 在等你。** 每个 Eitri 窗口都共享各自 agent 标签页的状态。`<prefix> u` 跳到等你最久的那个 agent，不管它在哪个窗口；`<prefix> B` 回到原来的地方。
- **聊天和页面交给合成器平铺。** 在 Hyprland、sway 和 niri 上，每个聊天、每个页面都开成单独的窗口；`window.tiling = "eitri"` 让它们都留在一个 Eitri 窗口里。
- **把终端里的 Neovim 搬进窗口。** 在 Neovim 0.12 或更新版本里运行 `:EitriOpen`，正在运行的这个 Neovim 连同没保存的改动一起进到 Eitri 窗口；关掉窗口，它回到终端。
- **接着上次的地方干。** 再次打开项目时，文件、分屏和光标位置都恢复原样；`<prefix> O` 列出你的其他项目。
- **Claude Code 标签页里能做的更多。** 计划模式、粘贴图片、把打开的缓冲区当作上下文，以及面板里的 vim 按键。
- **在另一台机器上的项目**（实验性，默认关闭）。`eitri host open example-host:/path` 打开放在一台 Linux 服务器上的项目：agent 在那边运行，你的 Neovim 留在自己的电脑上，配一份同步的副本。见[远程开发](../guide/remote-development.zh-CN.md)。

## 升级之前

- **用 `.deb` 或 `.rpm` 升级之后，运行一次 `eitri setup`。** 0.4.0 带的 agent sidecar 更新了，setup 会在你的机器上构建它（需要联网，构建期间约需 1.4 GiB 空闲磁盘）。`sh install.sh` 和 AUR 包会自己构建。
- **在 Hyprland、sway 和 niri 上，聊天和页面会离开 Eitri 窗口。** 想保持原样，在 `init.lua` 里加上 `eitri.config.set("window.tiling", "eitri")`。
- **前缀键后面多了几个默认按键：`F`、`S`、`_`、`W`、`O`、`u` 和 `B`。** 你的 `init.lua` 已经用 `eitri.keymap.set` 绑过的键仍归你，Eitri 会在启动时说一次哪个默认键没有绑上。
- **在把 Alt 当作 `$mod` 的 sway 或 i3 上，** 前缀键后面的 Alt 组合改成 Ctrl+Alt，除非你的 `init.lua` 设过其中任何一个。
- **`eitri-supervisor` 去掉了。** 加载 `agents-top` 页面，或者运行 `eitri agents --watch`，能看到同样的总览。
- **Eitri 启动的 Neovim 里关掉了 snacks.nvim 的平滑滚动，** 因为 Neovide 自己已经给滚动加了动画。想要回来，在你的 Neovim 配置里设 `vim.g.snacks_scroll = true`。
- **Markdown 预览里，`j`、`k`、`d`、`u`、`Ctrl+f`、`gg` 和 `G` 移动光标，页面跟着光标走。** `init.lua` 里写着 `scroll.half_down`、`scroll.half_up`、`scroll.page_down`、`scroll.top` 或 `scroll.bottom` 的修改会被忽略：改用 `cursor.half_down`、`cursor.half_up`、`cursor.page_down`、`cursor.first` 或 `cursor.last`。
- **0.4 的安装脚本不安装 0.3.0 或更早的版本。** 让它装旧版本，它会在下载任何东西之前停下。
