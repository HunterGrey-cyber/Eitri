# neovibe

An early prototype of the editor that became Eitri. At this point it is a
set of experiments: Neovide's renderer inside a GTK window, an agent panel
beside it, and the plumbing between them. Nothing here is meant to be
installed. This README is a placeholder written when the history was
published; the project was renamed Eitri on 2026-09-30, and the current
README is on the main branch.
